دریافت عمق بازار خرید (buyDepth)
​


از طریق این کانال می‌توانید سفارش‌های خرید موجود در Order Book یک بازار خاص را به‌صورت لحظه‌ای دریافت کنید. این داده‌ها برای نمایش لیست سفارش‌های خرید، تحلیل عمق بازار و طراحی ابزارهای معاملاتی بسیار کاربردی می‌باشند.


توجه داشته باشید که هر پیام یک 
اسنپ‌شات کامل
 از عمق بازار می‌باشد، نه تغییرات آن. یعنی با رسیدن هر پیام باید لیست قبلی را کنار بگذارید و لیست جدید را جایگزین کنید. این موضوع در هر سه روش زیر یکسان است.


جهت دریافت این کانال سه روش وجود دارد.


ورژن ۱ (منسوخ شده)
​


منسوخ شده
ورژن ۱ (
wss://api.wallex.ir/ws
) منسوخ شده است. این ورژن هنوز کار می‌کند، اما کانال‌های جدید مانند 
قیمت منصفانه
 و 
کندل چارت
 فقط روی ورژن ۲ (سنتریفیگو) در دسترس هستند.
برای پیاده‌سازی جدید از ورژن ۲ استفاده کنید. برای انتقال کد فعلی، 
راهنمای مهاجرت
 را ببینید.


آدرس اتصال WebSocket
​


برای اتصال باید از آدرس زیر استفاده کنید.


wss://api.wallex.ir/ws


فرمت پیام Subscribe
​


جهت دریافت عمق بازار باید پیام خود را با فرمت زیر ارسال کنید و می‌توانید هر مارکتی را جایگزین MARKET قرار دهید.


["subscribe", { "channel": "MARKET@buyDepth" }]


مثال


["subscribe", { "channel": "BTCTMN@buyDepth" }]
["subscribe", { "channel": "USDTTMN@buyDepth" }]
