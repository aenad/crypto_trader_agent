لیست معاملات انجام شده
​


جهت دریافت آخرین معاملات انجام شده، میتوانید از API زیر استفاده کنید.

توجه داشته باشید استفاده از API به طور مکرر جهت دریافت لیست معاملات توصیه نمیشود و ممکن هست با Rate-Limit مواجه شوید.

جهت دریافت لیست آخرین معاملات انجام شده میتوانید به 
آموزش سوکت لیست معاملات
 مراجعه کنید.


GET /v1/trades
