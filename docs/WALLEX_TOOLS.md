# نگاشت ابزارهای واقعی والکس

طبق schema دریافت‌شده از سرور، طبقه‌بندی بر اساس کلمات حذف و نام ابزارهای خواندنی ثابت شد:

| نقش | ابزار |
|---|---|
| بازار | wallex_spot_get_markets |
| آخرین معاملات عمومی | wallex_basic_get_latest_trades |
| کندل | wallex_basic_candle_history |
| موجودی حساب | wallex_basic_get_account_balances |
| تاریخچه سفارش | wallex_spot_get_orders |

متغیرهای قدیمی MCP_TOOLS_* در تنظیمات فعلاً استفاده نمی‌شوند. ابزارهای مارجین، OTC و تغییردهندهٔ حساب در این نگاشت نیستند. نقش orders فقط خواندن تاریخچه است؛ سفارش جدید ارسال نمی‌کند.

`GET /api/ticker/BTC/USDT` پاسخ آخرین معاملات عمومی را در data برمی‌گرداند. این قیمت تضمین اجرای سفارش نیست؛ زمان received_at زمان دریافت محلی است و تازگی معامله را ثابت نمی‌کند. زمان و قیمت معاملات از پاسخ اصلی قابل بررسی‌اند.

نماد به BTCUSDT تبدیل می‌شود. برای کندل، interval به resolution و بازهٔ زمانی Unix تبدیل می‌شود؛ پارامترهای interval/limit دیگر مستقیم به MCP ارسال نمی‌شوند. زمان پایان پیش از شروع کندل جاری انتخاب می‌شود.

پاسخ بازارهای تودرتو و نمادهای فشرده و نیز کندل‌های ستونی t/o/h/l/c/v پشتیبانی می‌شوند. صحت نهایی شکل پاسخ باید با دادهٔ واقعی سرور بررسی شود.

health موفق و فهرست ابزارها، ارتباط MCP را تأیید می‌کنند؛ اعتبار کلید و دسترسی خصوصی فقط با فراخوانی موفق ابزار خصوصی تأیید می‌شود. اجرای سفارش واقعی هنوز فعال نیست.
